# مران اللعبة

نسخة لعبة منفصلة عن تطبيقَي **مران الكلمات** و**قواعد**: نفس الكلمات (٤٣٦٨ كلمة) والقصص الـ٨٨ وتسجيلاتها، ودروس القواعد والنطق الـ١١٢ بتسجيلاتها، بس على شكل رحلة يومية بألعاب.

## كيف بيمشي اليوم

1. **مراجعة القديم:** الكلمات والقواعد اللي إجا وقتها، بألعاب سريعة.
2. **قاعدة اليوم:** شرح قصير ببطاقات (الفكرة، الجدول، أمثلة مسموعة، أشهر الأغلاط)، وبعدين ألعاب من أسئلة الدرس: اختيار، كمّل الفراغ، صيد الغلطة، رتّب الجملة، ترجم بالقطع، صح ولا غلط، ودروس النطق (صنّف الصوت، الحرف الصامت، وين الضغطة).
3. **محطات قصة اليوم:** كل قصة مقسومة لـ٦ محطات تقريبًا (٨–٩ كلمات). كل محطة: تعرّف على الكلمات، توصيل، فقاعات، سماع، تركيب الحروف، وإكمال جمل من القصة.
4. **تحدي القصة:** تسمع القصة كاملة مع تظليل كل كلمة، وبعدين تحدي. لما تخلصه، القصة بتصير متقنة وبكرة بتبدأ قصة جديدة.

وكمان: **🎧 كلمات القصة** (اسمع كلمات القصة بس، كلمة ورا كلمة، مع التحكم بالتكرار والسرعة والاستراحة والمعنى بالعربي بصوت)، **القاموس** (بحث بالإنجليزي أو العربي، وكل شكل من أشكال الكلمة على سطر لحاله مع معناه، والمواضيع الـ٥٢، والأضداد والمرادفات)، تبويب القواعد بالمستويات الثلاثة، صالة ألعاب (سباق الدقيقة، مطر الكلمات، الذاكرة، تحدي السمع، الفقاعات، ركّب الكلمة، رادار الأغلاط، ابنِ الجملة)، صندوق مراجعة، نقاط ومستويات وجواهر وشخصيات.

## مستقل عن مران

اللعبة بتحفظ تقدّمها لحالها (`miran-game.v1`) وما بتغيّر إشي بتطبيق مران. أول مرة بتفتحها، بتنسخ تقدّمك من مران كنقطة بداية بس.

## تشغيله

**على الجوال (أندرويد، بدون نت):** نزّل وثبّت التطبيق: https://github.com/mhoaltanany-max/miran-game-mho/releases/latest/download/miran-game.apk

**على الكمبيوتر:** نزّل المستودع (Code ← Download ZIP)، فك الضغط، وافتح `index.html` بـ Chrome أو Edge.

**على الموبايل كتطبيق:** فعّل GitHub Pages (Settings ← Pages ← Branch: `main` / root)، افتح الرابط، ومن قائمة المتصفح اختار "إضافة للشاشة الرئيسية".

## الملفات

| الملف | المحتوى |
|---|---|
| `index.html` · `game.js` | اللعبة |
| `data.js` | الكلمات والقصص والترجمات وتوقيت كل كلمة |
| `gdata.js` · `g/*.webm` | دروس القواعد والنطق وتسجيلاتها |
| `a/p*.js` | تسجيل صوتي لكل كلمة |
| `s/Story_NN.webm` | تسجيلات القصص الـ٨٨ |
| `sw.js` · `manifest.webmanifest` | التشغيل بدون نت والتثبيت على الموبايل |

## مفتاح التوقيع

الملف `signing/release.keystore` هو مفتاح توقيع التطبيق الدائم، عشان كل نسخة جديدة تنثبت فوق القديمة. لا تحذفه.
