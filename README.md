# مران اللعبة

نسخة لعبة منفصلة عن تطبيق **مران الكلمات**: نفس الكلمات (٤٣٦٨ كلمة) ونفس القصص الـ٨٨ وتسجيلاتها، بس على شكل رحلة يومية بألعاب.

## كيف بيمشي اليوم

1. **مراجعة القديم:** الكلمات اللي إجا وقتها من القصص السابقة، بألعاب سريعة.
2. **محطات قصة اليوم:** كل قصة مقسومة لـ٦ محطات تقريبًا (٨–٩ كلمات). كل محطة: تعرّف على الكلمات، توصيل، فقاعات، سماع، تركيب الحروف، وإكمال جمل من القصة.
3. **تحدي القصة:** تسمع القصة كاملة مع تظليل كل كلمة، وبعدين تحدي. لما تخلصه، القصة بتصير متقنة وبكرة بتبدأ قصة جديدة.

وكمان: صالة ألعاب (سباق الدقيقة، مطر الكلمات، الذاكرة، تحدي السمع، الفقاعات، ركّب الكلمة)، صندوق مراجعة، نقاط ومستويات وجواهر وشخصيات.

## مستقل عن مران

اللعبة بتحفظ تقدّمها لحالها (`miran-game.v1`) وما بتغيّر إشي بتطبيق مران. أول مرة بتفتحها، بتنسخ تقدّمك من مران كنقطة بداية بس.

## تشغيله

**على الكمبيوتر:** نزّل المستودع (Code ← Download ZIP)، فك الضغط، وافتح `index.html` بـ Chrome أو Edge.

**على الموبايل كتطبيق:** فعّل GitHub Pages (Settings ← Pages ← Branch: `main` / root)، افتح الرابط، ومن قائمة المتصفح اختار "إضافة للشاشة الرئيسية".
